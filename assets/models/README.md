# Modèles 3D

Les répertoires `animals/`, `food/` et `environment/` reçoivent les modèles
GLB Kenney CC0 facultatifs.

Depuis la racine du projet : `python tools/download_cc0_assets.py`.

Le jeu utilise les modèles procéduraux GDScript si un GLB manque. Aucun
téléchargement n'est requis pour lancer le MVP.
